# Earshot 녹음 대본

## 방법

- 저장 위치: `D:\meta\data\audio\raw\`  (폴더는 이미 만들어 둠)
- 파일명: **ID 그대로** (`L01.m4a`, `K03.wav` …). 확장자는 아무거나 (m4a / mp3 / wav / webm). 변환은 내가 함.
- 한 파일 = 한 줄. 앞뒤 0.5초쯤 비워 두고.
- 무전 느낌: 또박또박, 평소보다 살짝 빠르게. **L08 / K07 / K10 / M01 / M02**는 숨차고 급하게.
- 한 사람 목소리로 다 해도 됨. 가능하면 지휘대장은 낮고 침착하게.
- 괄호 안은 읽지 않음. "…"는 잠깐 끊김 (무전 끊기는 느낌).

## 우선순위

- **A (필수, 24줄)**: L01–L11, L13 (12줄) + K01–K10 (10줄) + M01, M02
- **B (선택, 12줄)**: E01–E10 + M03, M04 — 안 하면 Windows TTS(Zira)로 대체하고 README에 공개함.

끝나면 "녹음 끝"이라고 한 줄만 보내줘.
